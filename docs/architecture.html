Curtail: governed multi-agent curtailment administration on Google Cloud
A four-node ADK graph that takes a discharge reading for one of two California gages, classifies it against the drought emergency minimum flows in 23 CCR 875, computes which priority grouping under 875.5 a curtailment must reach, and drafts the order for a human official. Exactly one node calls a model. The Sentinel, the Allocation Core and Herald are deterministic Python, so every legally operative number is computed rather than generated, and the single generative step is fenced by five guards before its output can reach a document, a recipient, or a signature.
Sources of record
The reading unsourced Discharge and timestamp supplied by the caller. Every response says so: this service classifies a reading, it does not fetch one.
Untrusted order text A published order PDF is attacker-reachable input. It travels in the user message, never in agent session state.
State Water Board Published curtailment orders and their Attachment A rights tables. Fetched and parsed offline.

ADK Workflow “curtailment” · START to Sentinel to Core to Scribe to Herald
Gage Sentinel no model Classifies a reading against the date-period minimum. Flags near-threshold within 10 cfs.
Allocation Core no model The 875.5 priority ladder. Emits a per-right justification ledger, and RECOMMENDS. It never determines.
Order Scribe the only model call Drafts the order and its addenda for signature. Its output is data to be checked, never authority.
Herald no model Two lanes kept apart: Water Code 1121 legal service, and 875(d)(2) notification. Delivered is never service.
Five guards, in this order, around the one model call
Injection sanitizer Neutralises model-directed spans and fences the text. Oversize documents are REJECTED, never truncated into something that parses.
Model Armor evidence, not a veto Screens the RAW text. The verdict is carried to the watermaster, never used to refuse: an injected document must not be able to veto an order.
Citation scrubber Deterministic, AFTER the model. Strips any legal authority absent from the verified allowlist.
Ledger validation Rejects any draft asserting a right, priority date or tier the Core did not compute. Retry once, then escalate.
Distribution gate An escalated draft never reaches Herald at all. A guard on the document is worthless without one on the path to a person.
State, and its honest limit
Committed rights record Shasta and Scott Attachment A, sha256-pinned and re-checked at load. Travels inside the image.
Generated fact sheet Every judged figure computed from source, served at /api/facts. CI fails if it drifts.
No persistent store stated, not hidden Nothing survives a request today. The Season Ledger's statutory clocks are computed, not yet stored.
Managed services, and how each is reached
Vertex AI gemini-3.5-flash through the google-genai SDK, location global. The single generative call in the system.
Agent Registry Four agents published for cross-department discovery, generated from the graph's own node names. Registered by an operator script, not called per request.
Cloud Trace OpenTelemetry. ADK emits a span per node, so one traversal is one end-to-end reasoning chain.
Nothing self-executes
Draft order Authority, findings, the curtailed rights, exceptions and certification. Marked DRAFT throughout.
Approval queue A draft that fails a guard arrives here labelled UNVERIFIED, and is never served to anyone.
The watermaster 23 CCR 875(b) vests the determination in this person. 875(b)(3) preserves their discretion to decline.
Service and notice Counted separately. Contact details are synthetic and the system labels them so.
What this diagram deliberately does not show. There is no database, no queue and no scheduler, because the shipped code has none: the rights record is a hash-pinned file inside the image and every request recomputes from it. The No persistent store node is drawn rather than omitted, because a diagram that quietly leaves out what a system lacks is a claim as much as one that invents what it has. Every component above resolves to shipped code, and test_architecture_diagram.py fails the build if this file names a Google Cloud service, a model or an agent the repository does not actually use.
